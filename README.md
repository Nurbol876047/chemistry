# Жас химик зертханасы

7-9 сынып оқушыларына арналған цифрлық лабораториялық журнал платформасы. Оқушы каталогтан
тәжірибе таңдайды, қауіпсіздік чек-листін толтырады, үйде тәжірибе жасап, бақылауларды
журналға жазады және ИИ көмегімен нәтиженің түсіндірмесін алады. Мұғалім сынып журналдарын
тексеріп, баға мен пікір қояды.

## Стек

- Next.js 16 (App Router) + TypeScript + Tailwind CSS 4
- Recharts (pH графигі), lucide-react (иконкалар)
- Деректер қоймасы: `localStorage` (MVP), құрылымы Supabase-ге көшіруге дайын
- ИИ-талдау: Gemini API, сұраныс серверлік `/api/analyze` route арқылы жіберіледі — кілт
  клиентке шықпайды

## Іске қосу

```bash
npm install
npm run dev
```

Браузерде [http://localhost:3000](http://localhost:3000) ашыңыз. Кіру экранында «Оқушы» немесе
«Мұғалім» рөлін таңдап, «Тәжірибені бастау» батырмасын басыңыз (нақты тіркелу жоқ, бұл — демо
профиль).

Мұғалім рөлінде 5 демо оқушының толтырылған хаттамалары дайын тұрады (әртүрлі статуста: жаңа,
тексеруге жіберілген, тексерілген, қайта жасауға қайтарылған).

## ИИ API кілтін қосу

`/api/analyze` route Gemini API-ды шақырады. Жобаның түбірінде `.env.local` файлын жасап, оған
кілтті қосыңыз:

```bash
GEMINI_API_KEY=сіздің_кілтіңіз
# қаласаңыз, модельді де өзгертуге болады (әдепкі: gemini-2.0-flash)
GEMINI_MODEL=gemini-2.0-flash
```

Кілт қойылмаса, «Талдау алу» батырмасы жергілікті (демо) талдауды көрсетеді — платформа ИИ-сіз
де толық жұмыс істейді, тек талдау мәтіні қарапайымырақ болады.

## Жоба құрылымы

```
app/                       — беттер (App Router)
  (main)/                  — бүйір мәзірі бар беттер (каталог, журнал, мұғалім панелі...)
  api/analyze/route.ts      — Gemini API-ға серверлік сұраныс
components/                — Sidebar, TopBar, AppShell және ui/ (Card, Badge, Table, Checklist, Timer)
context/AppContext.tsx     — рөл, оқушы профилі және журнал жазбаларының ортақ күйі
data/experiments.ts        — 6 тәжірибенің толық мазмұны
data/safety.ts             — қауіпсіздік ережелері мен тыйым салынған қоспалар
data/reference.ts          — терминдер, pH шкаласы, тұрмыстық заттар кестесі
data/demoJournal.ts        — мұғалім панеліне арналған демо-деректер (5 оқушы)
lib/                        — типтер, localStorage көмекшілері, Gemini клиенті
```

## Толық нұсқаға көшу

MVP деректері `localStorage`-та сақталады. Толық нұсқа үшін `lib/storage.ts`-тегі
функцияларды Supabase сұраныстарына ауыстырып, `JournalEntry` типін (`lib/types.ts`) кесте
схемасы ретінде пайдалануға болады — деректер құрылымы бұған дайын етіп жасалған.
